## What's picked / shipped

**Composition: editorial split (was variant `C4-hover` in the demo set).**
Left column = duotone'd BW portrait + album-cover overlay layered via CSS
`mix-blend-mode: overlay`. Right column = wordmark (Caprasimo) + brutalist
stem toggles + wireframe terrain at bottom + listen-on row.

**Hover behaviour (REVERSED from the original spec):**
- Default state: cover at 90% opacity, `saturate(1.45)` — the heavy double-
  exposure is what the user sees first
- Hover: cover pulls back to 35% opacity, `saturate(1)` — portrait reveals
- Reads as "peek behind the cover"

**Wordmark font:** Caprasimo — kept after multiple font-picker rounds
(`/fonts` page exhausted, user stayed with the existing).

**Terrain (the WebGL "ground"):**
- Single Canvas, single PerspectiveCamera, single PlaneGeometry(180×90)
- Vertex displacement only — no shading. `MeshBasicMaterial` would have
  worked; we use `ShaderMaterial` with a trivial fragment shader emitting
  solid `--color-primary-mid` to keep the displacement vertex shader.
- Position: `bottom: 0`, `height: 50vh` of the right column inside the
  editorial split (so it occupies the lower-right quadrant)
- Audio inputs: bass / drum-kick / drum-body (continuous mid) / mid / high.
  `uDrumSolo` uniform ramps to 1 when drums is the only unmuted stem so
  the kick + drum-body layers scale up to ~2.6× during the solo phase.

**Onboarding sequence (`startPlaybackOnboarded` on `useAudioEngine`):**
- Drums fires immediately (t=0 on `ctx.resume()` resolving)
- Bass at t=4000ms, Main at t=8000ms, Vox at t=12000ms
- All gains set to 0 BEFORE audio starts so frame 0 is silent
- Any user `toggleMute` or `togglePlayback` cancels remaining auto-on timers

**Wordmark ghosts (kick-driven glitch):**
- Drums analyser feeds `Wordmark`. rAF reads kick band, transient detector
  fires `pulse = 1` on detected hits, decays ~16% per frame
- While pulse is alive, per-frame random translate + skew jitter (gated by
  pulse²) glitches each ghost; settles still when pulse → 0
- Main "9cups" stays static — only the three ghost copies behind it move

**Image pipeline:**
- `sharp` pre-optimises sources at build time (saved to
  `public/covers/catching-a-feeling.{webp,jpg}` and
  `public/artist/maz-bw-{wide,portrait}.{webp,jpg}`)
- Album cover: 1531KB → 136KB (91% smaller); headshot: 7200KB → 198KB (97%)
- `next/image` generates smaller AVIF/WebP variants per browser at runtime

**Duotone tech:**
- `components/ImageDemo/Duotone.tsx` — `duotoneMatrix(darkHex, lightHex)`
  precomputes a 4×5 SVG `feColorMatrix` from any two hex inputs using NTSC
  luminance (0.299 R + 0.587 G + 0.114 B) — `out_c = darkC + L * (lightC - darkC)`.
- Current home uses dark `#1F0F35` → light `#A56AC9` (a soft purple ramp
  that gives the blend more colour to chew on than pure BW would).

## Performance

Single Canvas refactor + built-in materials made this hit solid 60fps on a
mid-tier MacBook (claimed by the user). Key constraints from research:
- Wireframe vertex displacement on a 16k-vert plane is the cheapest "good
  looking" WebGL pattern. Confirmed.
- Antialias OFF, dpr=1, no transparent overdraw on solid meshes
- All built-in materials (`MeshBasicMaterial`, `PointsMaterial`) — no custom
  fragment shaders covering the canvas
