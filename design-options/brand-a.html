02 — Typography

Type System

Primary — IM Fell English (Wordmark / Headings)

Nine of Cups

"Round, unhurried, slightly archaic. Literary, not corporate."

Old-style serif. Used for the brand wordmark, release names, and display headings.

Display — Bebas Neue (Web / Large Scale)

9CUPS

Condensed sans-serif for web display and promotional material. Swiss-inspired, strong edges. Complements IM Fell English without competing.

Body — Space Grotesk (Secondary / UI)

Clean, geometric, modern

Used only where legibility demands it. Secondary text should feel like a caption, not a label. Light weight preferred. Never cold, never techy.

Also applies: extreme tracking on secondary lines (event details, dates, platforms).
